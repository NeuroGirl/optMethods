### Как использовать код решения?

Код решения нужно загрузить и запустить. В консоли вам будет необходимо ввести саму задачу в формате:

- коэффициенты переменных целевой функции через пробел
- коэффициенты переменных ограничений через пробел, знак(<=, >=, =), коэффициент справа (количество строк равно количеству ограничений, если переменная не участвует в ограничении, ее коэффициент обозначается 0)
- когда закончите вводить ограничения, нажмите Enter для пропуска строки
- min / max в зависимости от задачи (максимизации или минимизации)
